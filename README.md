# FPS将棋

将棋盤で相手の駒を取りに行くと、両者がその駒を一人称視点で操作して決闘します。相手の王を決闘で倒すと勝利です。

## Windows版で遊ぶ

1. [v0.14.0の配布ページ](https://github.com/dugite-git/FPSshogi-Releases/releases/tag/v0.14.0)を開き、「Assets」から **FPSshogi-Windows.zip** をダウンロードします。
2. ZIPをすべて展開し、展開先の `FPSshogi.exe` を起動します。
3. 1台のPCで遊ぶときは「オフライン対局」を選びます。コントローラー2台、またはキーボード・マウスとコントローラー1台で参加できます。「オンライン対局」では、両方のPCでSteamにサインインしてゲームを起動し、相手を部屋に招待します。

駒をひとりで試すときは、タイトルから「練習場」を選んでください。操作方法とv0.6.1からの変更は、[日本語パッチノート](https://github.com/dugite-git/FPSshogi-Releases/releases/tag/v0.14.0)で読めます。
