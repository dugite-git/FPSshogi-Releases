# FPS将棋

## どんなゲーム？

相手の駒を取ろうとすると、双方が駒を一人称視点で操作して決闘する将棋です。相手の王を決闘で倒せば勝ちです。通常の9×9と、5×5の「5五将棋」が遊べます。

## 遊ぶには

Windows PCで[最新版のZIP](https://github.com/dugite-git/FPSshogi-Releases/releases/latest/download/FPSshogi-Windows.zip)をダウンロードし、すべて展開して `FPSshogi.exe` を起動します。

- **オフライン対戦**：コントローラー2台、またはキーボード・マウスとコントローラー1台を用意します。
- **オンライン対戦**：2人ともSteamにサインインします。
- **ひとりで試す**：タイトルから「練習場」を選びます。

> **オンライン対戦の注意**：異なるバージョン同士では対戦できません。2人とも同じリリースのWindows版ZIPを使ってください。迷ったら、両方とも上のリンクから最新版をダウンロードしてください。
